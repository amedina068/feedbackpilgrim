# Support

This page tells you where to get help with Feedback Pilgrim.

## Read the documentation

The documentation is at [feedbackpilgrim.com/docs](https://feedbackpilgrim.com/docs). It explains the install, the configuration, the API, the MCP server and the SDKs. [INSTALL.md](INSTALL.md) gives the install steps for an AI agent.

## Ask a question

Ask questions in the [Q&A category of the discussions](https://github.com/amedina068/feedbackpilgrim/discussions/categories/q-a). Search the existing discussions before you start a new one. Give the version, the install method and the steps that you tried.

Do not open an issue for a question. The issues are for bugs and feature requests.

## Report a bug or ask for a feature

Open an issue with the [bug report form](https://github.com/amedina068/feedbackpilgrim/issues/new?template=bug_report.yml) or the [feature request form](https://github.com/amedina068/feedbackpilgrim/issues/new?template=feature_request.yml). Share an idea that is not ready for an issue in the [Ideas category](https://github.com/amedina068/feedbackpilgrim/discussions/categories/ideas).

## Report a security problem

Do not report a security problem in an issue or a discussion. Read [SECURITY.md](SECURITY.md) and report the problem in private.

## Response time

One person maintains this project, so answers are not immediate. The maintainer reads each question, but a reply can take some days.
